# 模型、提示词与已知限制

本文描述 0.1.0 源码实现范围，不代表所有服务商账号都完成真实联调。

## 模型连接

应用提供 DeepSeek、Kimi、阿里云百炼、智谱和自定义连接模板，使用兼容 Chat Completions 的消息请求。地址和模型 ID 可编辑，模型列表能否获取取决于服务端、地域和账号权限。

预填型号和参考列表只是配置起点，实际可用型号以服务商返回结果为准。自定义端点的流式格式、结束标记和返回字段需要兼容应用协议。

## 四种模式

| 模式 | 实际行为 |
| --- | --- |
| 关闭 | 不追加额外思维配置；角色人设、记忆及上下文仍发送 |
| 官方 API 配置 | 使用已接入协议的专用字段发送思考前缀，按端点和型号检查能力 |
| 第三方指令配置 | 将可编辑文本放在 system 开头或本次 user 内容开头，不改变消息角色 |
| 普通提示词 | 在系统提示中追加普通文本规则 |

官方思考前缀适配器当前仅放行 DeepSeek 原厂端点及代码列明的 deepseek-flash、deepseek-v4-pro，使用 beta 接口、prefix 和 reasoning_content。这不代表任意 DeepSeek 托管服务或其他厂商都支持。实现以 src/lib/cot/provider-adapters.ts 为准，真实端点接受度仍需验证。

七项第三方预设为 Harmony analysis、DeepSeek 思考标记、Qwen3 /think、ChatML assistant、Llama 3 assistant、Gemma model 回合和【PERSONA_LOAD】。它们可复制后编辑，来源及限制保留在应用详情中。

原始协议头插入普通 API 消息后仍是消息文本，不能据此认定原生聊天模板已启用。/think 的文档适用范围和服务端条件也不应外推到所有型号。应用只显示服务端实际返回的内容，不保证返回思考过程。

## 已知限制

- 大量历史消息仍有全量读取与搜索扫描，尚未完成分页和规模化优化。
- 流式思考块在正文首次到达时可能自动折叠，手动展开意图的保留仍有改进空间。
- 当前尚无全量角色/模型/图片备份导入，聊天 JSON 导出不能当作完整恢复方案。
- Android、Web 使用不同存储实现，Web Key 仅在页面会话中保留。
- 当前以 Android 为主要目标，iOS 未完成运行验收。
- 自动回归和构建成功不替代真实手机、网络异常及服务商账号联调。
