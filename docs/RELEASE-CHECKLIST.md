# 发布检查清单

用于准备 Android 正式发行版。当前版本的安装包与校验和见 [0.1.1 发布页](https://github.com/rzhuzi/Lingban/releases/tag/v0.1.1)。

## 版本与源码

- [ ] 应用配置、package.json 和 lock 文件的版本号一致，Android versionCode 已递增。
- [ ] 从待发布提交构建，工作区没有未确认的改动。
- [ ] lint、类型检查与自动回归通过，必需的 CI 检查通过。
- [ ] 数据迁移与读取兼容性检查通过。
- [ ] 代码、配置、文档和提交内容中没有密钥、私人资料或个人开发记录。

## 安装包

- [ ] 生成 ARM64-v8a 和通用版两个 APK，保持相同的包名、应用版本、versionCode 和发布证书。
- [ ] 确认 ARM64-v8a 包仅包含 arm64-v8a，通用包包含计划支持的全部架构。
- [ ] 核对 Release 构建、包名、版本、最低系统版本及非调试标记。
- [ ] 验证发布签名、16 KB APK 对齐和运行时依赖单例。
- [ ] 计算两个 APK 的 SHA256，生成 SHA256SUMS.txt，并核对上传后的附件。
- [ ] 妥善备份签名密钥和恢复凭据，不将凭据放入源码或发布附件。

## 设备与功能

- [ ] 在目标设备上检查安装与覆盖升级。
- [ ] 检查模型配置、连续聊天、停止与重试、角色切换和历史查看。
- [ ] 检查重启后的数据保留、聊天导出及数据清理。
- [ ] 检查浅色、深色、系统主题和字体缩放。
- [ ] 使用已脱敏的测试资料检查模型服务连接与错误提示。

## 公开页面

- [ ] 中英文 README、更新日志和下载说明与实际版本一致。
- [ ] 发布说明介绍功能、变化、安装方式和用户需要知道的限制。
- [ ] 清晰标注 ARM64-v8a 推荐包和通用包，说明二选一安装。
- [ ] 发布附件仅包含面向用户的安装包、校验和及必要材料。
- [ ] 核对资源来源、再分发授权和 [NOTICE](../NOTICE.md)。
- [ ] 页面截图不包含 API Key、私人聊天或个人资料。
- [ ] 正式版取消 Pre-release 标记，并按版本计划设置 Latest。
- [ ] 发布后检查下载链接、附件校验和和仓库首页入口。
